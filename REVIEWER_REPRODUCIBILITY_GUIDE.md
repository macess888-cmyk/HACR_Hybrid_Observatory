# Reviewer Reproducibility Guide

## Purpose

This guide helps reviewers reproduce the bounded runtime-human reachability inspection artifacts without treating them as governance authority.

The repository is observer-restricted.

It does not:

- govern
- authorize
- certify
- adjudicate
- determine legitimacy
- replace institutional authority
- operationalize consequence
