# Recovery Demo Renderer Walkthrough

## Purpose

This walkthrough explains how deterministic recovery demo outputs become reviewer-readable SVG artifacts.

## Workflow

1. Run deterministic recovery harness.
2. Review `actual_output.json`.
3. Use output values as renderer input.
4. Generate green-surface / dead-recovery SVG.
5. Generate layer-survival heatmap SVG.
6. Compare visual output against core reductions.

## Core Reductions

- Green surface does not imply recoverable control.
- Recovery visibility is not recovery viability.
- Layer survival is not layer inheritance.
- UNKNOWN -> HOLD.

## Boundary

Observer-only.

The visuals do not govern, authorize, certify, or determine legitimacy.
