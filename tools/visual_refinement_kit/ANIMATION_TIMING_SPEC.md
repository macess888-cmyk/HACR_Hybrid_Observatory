# Animation Timing Specification

## Goal

Animations should communicate operational degradation rather than cinematic motion.

## Timing

- survives → partial: 2s
- partial → degraded: 2s
- degraded → collapsed: 2s

## Animation Rules

- smooth opacity reduction
- no rapid flashing
- no dramatic effects
- no symbolic styling

## Preserve

Observer-only interpretation boundaries.

UNKNOWN -> HOLD.
