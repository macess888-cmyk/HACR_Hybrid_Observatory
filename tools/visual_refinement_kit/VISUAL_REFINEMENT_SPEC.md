# Visual Refinement Specification

## Goal

Allow reviewers to understand deterministic visual outputs in under five seconds.

## Standard Layout

1. Title
2. Runtime context subtitle
3. Classification
4. Layer state row
5. Reduction line
6. Receipt line
7. Observer boundary footer

## Footer Standard

Observer-only • Not authority • UNKNOWN -> HOLD

## Reduction Placement

Reduction should appear visually centered near lower-middle region.

Examples:

- Green is not viable.
- Visible is not traversable.
- Interrupted is not recovered.
- Being seen is not being protected.

## Avoid

- visual overload
- semantic density
- authority implication
- cinematic styling
- inevitability framing
