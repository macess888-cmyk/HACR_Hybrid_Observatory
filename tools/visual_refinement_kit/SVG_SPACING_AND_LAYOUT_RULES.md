# SVG Spacing And Layout Rules

## Minimum Spacing

- Title margin: 40px
- Subtitle margin: 20px
- Layer row spacing: 60px
- Reduction spacing: 80px
- Footer spacing: 50px

## Layer Layout

Preferred order:

observable
↓
inspectable
↓
traversable
↓
interruptible
↓
recoverable

## Color Standard

- Green  = survives / visible
- Yellow = unresolved / partial
- Red    = degraded
- Gray   = collapsed

## Goal

Reviewer comprehension within minimal traversal burden.
