# Visual Refinement Kit

## Purpose

This tooling standardizes SVG refinement, animation smoothness, screenshot consistency, deterministic mutation structure, walkthrough ergonomics, and reviewer traversal clarity across Observatory visual outputs.

- Visual polish improves traversal, not authority.
- Green is not viable.

- Layer survival is not layer inheritance.
