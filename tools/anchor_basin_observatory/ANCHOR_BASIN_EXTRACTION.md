# Anchor Basin Extraction

## Anchor Basin

An anchor basin forms when multiple anchors converge around a shared stability field.

## Candidate Objects

- ANCHOR_BASIN
- ANCHOR_CORE
- ANCHOR_CLUSTER
- ANCHOR_CONVERGENCE
- ANCHOR_PLATEAU
- ANCHOR_FIELD

## Boundary

Anchor basins are not prediction.

Anchor basins are not causality.

Anchor basins are not authority.

They only represent bounded historical stability concentration.
