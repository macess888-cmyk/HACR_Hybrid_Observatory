# Temporal Layer Stack Renderer — v11

Observer-only temporal continuity visibility renderer.

This tool renders bounded historical visibility across observation windows.

It shows how continuity ecology appeared to change across replayable review epochs.

It does not predict.
It does not certify causality.
It does not govern execution.
It does not route operations.
It does not establish operational truth.

## Purpose

The Temporal Layer Stack extends the renderer lineage:

Topology
→ Pressure
→ Weather
→ Climate
→ Adaptive Climate
→ Continuity Ecology
→ Temporal Ecology
→ Temporal Layer Stack

## Core Concept

Each observation epoch is rendered as a bounded layer.

Older epochs may appear as ghost layers behind later epochs.

Replay trajectories show reviewer-visible traversal across epochs.

Window deformation shows changes in visibility conditions, not system behavior.
