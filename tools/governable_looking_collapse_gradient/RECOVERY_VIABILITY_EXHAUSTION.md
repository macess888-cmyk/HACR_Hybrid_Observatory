# Recovery Viability Exhaustion

## Purpose

This model pressures whether recovery windows remain materially reachable before consequence hardens.

## Core Reduction

Recovery visibility is not recovery viability.

## Pressure Indicators

- escalation delay
- reconstruction timing exhaustion
- synchronization pressure
- continuation persistence
- dependency layering
- affected-human exhaustion
- replay locality fragmentation
- traversal saturation

## Failure Pattern

Recovery appears theoretically available while operationally becoming unreachable.

## Boundary

This model remains observational only.
