# Visual Style Guide

## Footer Standard

All visuals should preserve:

Observer-only • Not authority • UNKNOWN -> HOLD

## Color Standard

- Green  = survives / visible
- Yellow = partial / unresolved
- Red    = degraded
- Gray   = collapsed / exhausted

## Reduction Placement

Primary reduction should appear near the lower-middle visual region.

Examples:

- Green is not viable.
- Visible is not traversable.
- Interrupted is not recovered.
- Being seen is not being protected.

## Typography

Preferred:

- Arial
- Large title
- Minimal text density
- High contrast
- Clear reduction visibility

## Avoid

- authority implication
- predictive framing
- inevitability framing
- governance implication
- overloaded visuals
