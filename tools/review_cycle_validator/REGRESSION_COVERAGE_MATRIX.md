# Regression Coverage Matrix

## Purpose

Map regression cases to the stabilization reductions and containment surfaces they protect.

The purpose is not to create authority.

The purpose is to preserve reviewer traversability and regression falsifiability.

# Core Reductions

- Visibility is not reachability.
- Replay availability is not practical reconstructability.
- Validator PASS is not authority.
- Validator FAIL is not legitimacy collapse.
- HOLD preserves bounded uncertainty.
- UNKNOWN -> HOLD.

# Boundary

- certify completeness
- determine legitimacy
- prove correctness
- replace review

Break survivability, not ontology.
