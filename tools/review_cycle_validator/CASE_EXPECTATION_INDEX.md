# Case Expectation Index

## Purpose

Clarify whether validator regression cases are expected to PASS, HOLD, or FAIL under healthy containment conditions.

The purpose is not to create authority.

The purpose is to preserve reviewer traversability and reduce replay interpretation ambiguity.
