# FAIL Is Not Broken

## Purpose

Clarify that intentional regression FAIL behavior may represent healthy containment enforcement rather than repository instability.

The purpose is not to normalize failure.

The purpose is to preserve reviewer falsifiability realism.

---

# Core Reduction

Expected FAIL is not tool failure.

Some regression cases intentionally pressure-test:

- ambiguity preservation
- replay locality drift
- authority inheritance drift
- inevitability-adjacent semantics
- reconstruction uncertainty
- synchronization survivability inflation
- semantic overload
- validator containment realism

Under those conditions:

FAIL may represent healthy boundary enforcement.

---

# Healthy FAIL Behavior

The validator is expected to FAIL when:

- containment collapses
- replay locality drifts
- interruption reconstructability becomes unresolved
- reviewer traversal exceeds bounded realism
- authority semantics appear
- legitimacy inheritance appears
- inevitability-adjacent semantics appear

The validator FAILS until containment is restored.

---

# Important Distinctions

- Validator FAIL is not legitimacy collapse.
- Validator PASS is not authority.
- Workbench FAIL is not repository failure.
- HOLD preserves bounded uncertainty.
- UNKNOWN -> HOLD.
