# Terminology Normalization

## Purpose

Terminology normalization reduces semantic drift, duplication pressure, and ontology reopening risk.

This is stabilization work.

It is not conceptual expansion.

---

# Preferred Stabilized Terms

Use:

- runtime-local
- interruption reachability
- executable interruption
- practical reconstructability
- reviewer traversability
- replay realism
- deterministic replay
- bounded uncertainty
- semantic containment
- operational momentum
- continuation pressure

Avoid:

- institutional destiny
- inevitable outcome
- governance truth
- legitimacy proof
- hidden authority
- survivability metaphysics
- governance cosmology
- certainty production

---

# Core Locks

- Visibility is not reachability.
- Persistence is not legitimacy.
- Asymmetry does not imply destiny.
- Replayability does not create legitimacy.
- Renderer output is not proof.
- Reviewer traversal is not authority.
- Validator PASS is not authority.
- Validator FAIL is not legitimacy collapse.
- Validator HOLD preserves bounded uncertainty.
- UNKNOWN -> HOLD.

---

# Normalization Rule

Any new term must collapse back into:

- runtime locality
- executable interruption realism
- measurable asymmetry
- practical reconstructability
- bounded falsifiability

If it cannot:

UNKNOWN -> HOLD.

Break survivability, not ontology.
