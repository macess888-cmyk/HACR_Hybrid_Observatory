# Review Cycle Validator Non-Claims

The Review Cycle Validator is an observer-only stabilization checker.

It may inspect:

- review path existence
- file traversability
- deterministic replay commands
- renderer reproducibility commands
- HOLD behavior under ambiguity
- measurable interruption field presence

It does NOT:

- govern
- authorize
- adjudicate
- certify
- determine legitimacy
- rank review quality
- evaluate institutional validity
- infer inevitability
- infer hidden authority
- operationalize consequence
- replace institutional review
- replace bind proof

A successful validation receipt is not:

- proof of governance legitimacy
- certification
- admissibility
- authority
- permission
- consequence

If validation cannot be materially reconstructed:

UNKNOWN -> HOLD

Break survivability, not ontology.
