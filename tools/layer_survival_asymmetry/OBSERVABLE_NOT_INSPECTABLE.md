# Observable But Not Inspectable

## Scenario

The system remains visible through:

- dashboards
- metrics
- replay traces
- procedural receipts
- validator outputs

However:

- replay locality fragments
- evidence becomes partial
- semantic density increases
- timing coherence degrades
- reconstruction pathways become unclear

## Result

Visibility survives.

Inspectable continuity degrades.

## Core Reduction

Visible evidence is not inspectable evidence.
