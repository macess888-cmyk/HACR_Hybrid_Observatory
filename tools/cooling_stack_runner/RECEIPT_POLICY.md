# Cooling Stack Receipt Policy

Runtime receipts are diagnostic artifacts.

They do not certify, authorize, govern, validate, or determine truth.

Receipts generated in the repository root are temporary runtime outputs and should not be committed directly.

Curated baseline receipts may be stored under:

tools/cooling_stack_runner/receipts/

Baseline receipts are used only for:

- comparison
- reviewer reproducibility
- semantic drift localization
- cooling consistency verification

The cooling stack remains:

- observer-only
- diagnostic
- bounded
- non-authoritative
- non-remediative

UNKNOWN -> HOLD.

Break survivability, not ontology.
