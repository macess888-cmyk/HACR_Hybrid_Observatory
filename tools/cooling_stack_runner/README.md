# Cooling Stack Runner

Runs selected observatory artifacts through the cooling and interpretation hardening tools.

The runner is diagnostic only.

It does not:

- enforce
- certify
- authorize
- govern
- determine truth
- determine legitimacy

## Included Tools

- Semantic Cooling Auditor
- Visual Authority Drift Harness
- Recursive Importance Drift Auditor
- Falsifiability Preservation Harness
- External Interpretation Risk Scanner

## Usage

From repository root:

```bat
python tools\cooling_stack_runner\cooling_stack_runner.py
