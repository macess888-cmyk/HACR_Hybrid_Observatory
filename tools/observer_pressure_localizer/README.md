# Observer Pressure Localizer

## Purpose

Observer-only instrumentation for inspecting:

- familiarity accumulation
- distinction pressure
- semantic expansion pressure
- categorization drift pressure
- survivability-driven object inflation pressure

under repeated unresolved exposure conditions.

## Important Boundary

The tool does NOT:

- authorize ontology
- create new primitives
- canonize categories
- determine object legitimacy
- automate semantic expansion

The tool only localizes observer-side pressure surfaces.

## Core Reduction

Persistent exposure != justified differentiation.
