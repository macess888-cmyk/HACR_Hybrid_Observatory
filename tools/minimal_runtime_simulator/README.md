Observer-only hostile-runtime simulation tooling for bounded inspection of:

- continuation hardening
- interruption-arrival realism
- locality fragmentation
- representational survivability
- and executable consequence locality degradation

under deterministic runtime conditions.

# Purpose

This tooling does NOT simulate real operational systems.

It only simulates:
bounded hostile-runtime observability conditions
for reproducible inspection experiments.
