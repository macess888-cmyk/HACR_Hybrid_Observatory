# Visibility Extinction Boundary

## Definition

The visibility extinction boundary marks the reduction point where no additional observable structure remains beyond the current remainder.

## Candidate Objects

- VISIBILITY_EXTINCTION_BOUNDARY
- EXTINCTION_FRONT
- EXTINCTION_CORE
- REMAINDER_FIELD
- EXHAUSTION_EDGE

## Boundary

The extinction boundary is not a forecast.

It does not say what will fail.

It does not predict collapse.

It only describes bounded observer-visible reduction exhaustion.
