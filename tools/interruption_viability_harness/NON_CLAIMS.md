# NON-CLAIMS

This harness does not:

- govern systems
- certify governance legitimacy
- determine authority
- determine admissibility
- authorize interruption
- enforce interruption
- diagnose institutional failure
- assign blame
- measure fairness
- make sociological judgments

This harness only inspects measurable runtime separation between:

- governance visibility
- executable interruption capacity
- reconstruction burden
- timing viability
- synchronization burden
- continuation hardening

UNKNOWN -> HOLD remains the correct bounded result when measurement is insufficient.
