# How to Read Interruption Viability Receipts

This harness produces deterministic observer-side receipts for bounded runtime inspection.

## Status Meanings

### PASS

PASS means interruption appears materially executable within the measured runtime window.

PASS does NOT mean:

- governance is legitimate
- authority is valid
- admissibility is proven
- the system is safe
- interruption will succeed

### HOLD

HOLD means measurable runtime evidence is insufficient for PASS or FAIL.

HOLD preserves unresolved determination.

HOLD does NOT mean:

- approval
- failure
- legitimacy
- closure
- inevitability

### FAIL

FAIL means visible governance persists while executable interruption capacity appears materially collapsed under measured runtime constraints.

FAIL does NOT mean:

- governance is invalid
- institutional failure is proven
- authority is illegitimate
- blame is assigned
- sociological theater is diagnosed

## Core Boundary

Measurement is not legitimacy.

Instrumentation is not authority.

Visibility is not viability.

Persistence is not closure.

UNKNOWN -> HOLD remains the correct result when measurement is insufficient.
