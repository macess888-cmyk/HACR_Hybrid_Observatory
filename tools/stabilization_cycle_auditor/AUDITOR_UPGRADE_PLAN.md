# Auditor Upgrade Plan

## Goal

Keep the auditor:

- deterministic
- minimal
- understandable
- reviewer-affordable
- operationally useful

## Avoid

- dashboard complexity
- governance expansion
- visual overload
- ontology growth
- symbolic authority
- infrastructure mythology

## Safe Improvements

- tiny scoring refinement
- clearer reviewer outputs
- smaller traversal paths
- reproducibility checks
- deterministic QA
- reviewer burden reduction

## Preserve

One-click bounded operational clarity.
