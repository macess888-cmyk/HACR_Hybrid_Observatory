# Maturity Invariant

## Core Reduction

Healthy maturity:

- reduces traversal cost
- increases falsifiability
- reduces reassurance inheritance risk

under bounded reviewer conditions.

## Runtime Concern

A repository may become:

- larger
- smoother
- more visual
- more polished
- more coherent
- more operationally impressive

while simultaneously becoming:

- harder to traverse
- harder to reproduce
- harder to falsify
- more reassuring
- more authority-camouflaged
- and less operationally clear

## Preserve

Operational clarity under bounded reviewer effort.

## Runtime Reductions

- Maturity is not accumulation.
- Complexity is not legitimacy.
- More tooling is not more clarity.
- More visuals are not more falsifiability.
- A mature observatory must become easier to verify, not harder to admire.
- UNKNOWN -> HOLD.
