# Continuation Hardening Renderer

## Purpose

The Continuation Hardening Renderer is a deterministic, observer-only tool for inspecting bounded runtime topology where continuation hardening may outpace interruption constructability.

It does not recommend action, optimize interruption, or determine governance validity.

## Scope

The renderer may inspect:

- continuation hardening pressure
- interruption locality decay
- synchronization exhaustion
- consequence arrival compression
- escalation traversal delay
- dependency-weighted hardening zones

## Non-Claims

This tool does NOT:

- authorize interruption
- automate remediation
- optimize governance
- determine legitimacy
- predict inevitability
- certify escalation viability

## Output Semantics

Outputs are bounded observability artifacts only.

They localize where continuation hardening pressure appears under supplied runtime assumptions.

UNKNOWN -> HOLD.

Break survivability, not ontology.
