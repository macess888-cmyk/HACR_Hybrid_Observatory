# Receipt Integrity Verifier

Observer-only tooling for verifying deterministic hostile-runtime receipt structure.

## Focus

Verifies that receipts preserve:
- case identity
- semantic output
- runtime reductions
- observer-only boundaries
- non-authoritative constraints
- and reproducibility traceability.

## Non-Claims

This verifier does NOT:
- certify correctness
- authorize execution
- validate governance
- prescribe remediation
- or create operational authority.
