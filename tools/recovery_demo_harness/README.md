# Recovery Demo Harness

## Purpose

This deterministic harness demonstrates that surface continuity can remain green while recovery viability collapses underneath runtime pressure.

## Core Reduction

Green surface does not imply recoverable control.

## Demo Claim

A system may remain:

- dashboard-stable
- validator-passing
- replay-available
- procedurally coherent
- institutionally continuous

while effective recovery time exceeds the consequence-hardening window.

## Boundary

Observer-only.

This harness does not govern, authorize, certify, or determine legitimacy.
