# Representational Survivability Inspector

Observer-only inspection tooling for representation/runtime divergence localization.

## Runtime Focus

Detects conditions where:
- representation persists
- observability survives
- escalation appears active
- telemetry remains coherent

while executable consequence locality degrades operationally.

## Core Reduction

representation
!=
runtime reachability

## Observatory Boundary

This tooling localizes divergence surfaces only.

It does not:
- classify governance quality
- certify control
- authorize intervention
- determine legitimacy
