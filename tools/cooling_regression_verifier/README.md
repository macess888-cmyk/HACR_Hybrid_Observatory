# Cooling Regression Verifier

Compares cooling stack receipts across runs to localize semantic drift, cooling regressions, or stability improvements.

This verifier is diagnostic only.

It does not:

- authorize
- certify
- govern
- validate truth
- invalidate artifacts

It only compares observability signatures between runs.

## Purpose

The verifier helps localize:

- worsening semantic density
- authority drift increase
- external interpretation escalation
- falsifiability erosion
- recursive importance accumulation
- visual authority pressure growth

## Usage

```bat
python tools/cooling_regression_verifier/cooling_regression_verifier.py
