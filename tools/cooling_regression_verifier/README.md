# Cooling Regression Verifier

Compares structured cooling stack receipts to summarize semantic, visual, falsifiability, and external interpretation pressure.

This verifier is diagnostic only.

It does not:

- authorize
- certify
- govern
- validate truth
- invalidate artifacts
- resolve admissibility

## Usage

From repository root:

```bat
python tools\cooling_regression_verifier\cooling_regression_verifier.py
