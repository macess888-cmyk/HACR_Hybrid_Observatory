# One Click Review Pipeline

## Purpose

This tool lets a reviewer run the main Observatory demo and stabilization audit with one command.

## What It Does

1. Runs deterministic recovery cases.
2. Renders SVG visuals.
3. Runs stabilization health audit.
4. Checks that key files exist.
5. Writes one simple review summary.

## Core Reduction

A reviewer should not need to understand the whole repository to verify one bounded claim.

## Boundary

Observer-only.

Not governance.
Not authority.
Not certification.
UNKNOWN -> HOLD.
