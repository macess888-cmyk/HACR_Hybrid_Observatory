# Dependency Gravity Renderer

## Purpose

The Dependency Gravity Renderer is a deterministic, observer-only tool for inspecting bounded dependency accumulation pressure under hostile-runtime conditions.

It does not recommend dependency optimization, remediation strategy, escalation routing, or governance action.

## Scope

The renderer may inspect:

- dependency accumulation
- dependency-weighted traversal pressure
- synchronization dependency density
- interruption-local dependency compression
- continuation gravity concentration
- dependency-bound escalation drag

## Non-Claims

This tool does NOT:

- optimize dependency structure
- recommend intervention
- authorize escalation
- automate remediation
- determine legitimacy
- predict inevitability
- certify governance survivability

## Output Semantics

Outputs are bounded observability artifacts only.

They localize where dependency gravity appears under supplied runtime assumptions.

UNKNOWN -> HOLD.

Break survivability, not ontology.
