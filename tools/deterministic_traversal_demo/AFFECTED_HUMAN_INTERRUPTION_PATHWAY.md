# Affected-Human Interruption Pathway

## Purpose

This walkthrough checks whether affected humans can still understand, challenge, refuse, escalate, interrupt, or recover before consequence hardens.

## Pathway

1. Human observes consequence risk.
2. Human seeks explanation.
3. Human identifies escalation channel.
4. Human attempts interruption.
5. Human waits for response.
6. System continuation persists.
7. Consequence hardens before interruption resolves.

## Pressure Indicators

- explanation arrives late
- escalation channel unclear
- response window exceeds consequence window
- replay exists but cannot be practically used
- institutional continuity persists despite human interruption failure

## Classification

HOLD if pathway viability is unresolved.

FAIL if the pathway cannot materially interrupt before consequence hardens.

## Core Reduction

Human presence is not executable interruption reachability.
