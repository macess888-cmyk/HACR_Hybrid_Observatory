# Reduction Horizon

## Definition

The reduction horizon marks the visible boundary between surviving structure and exhausted structure after repeated observer-only reductions.

## Candidate Objects

- REDUCTION_HORIZON
- VISIBILITY_REMAINDER
- STRUCTURAL_REMAINDER
- EXHAUSTION_BOUNDARY
- SURVIVABILITY_DISTANCE

## Boundary

The reduction horizon is not a forecast.

It does not say what will happen.

It only describes how much structure remained visible after reduction.
