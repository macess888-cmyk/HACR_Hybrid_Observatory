# Replay Locality Fragmentation Heatmap

## Purpose

This visualization localizes where replay remains technically visible while interruption reconstructability degrades underneath locality fragmentation.

## Core Reduction

Replay survivability is not replay traversability.

## Pressure Surface

Replay may remain:

- available
- synchronized
- validator-backed
- institutionally persistent
- procedurally coherent

while reconstruction collapses through:

- locality fragmentation
- dependency fragmentation
- synchronization drift
- reviewer traversal overload
- reconstruction timing exhaustion
- semantic density accumulation

## Visualization Targets

- replay islands
- synchronization gaps
- traversal dead-zones
- dependency saturation zones
- timing collapse corridors
- reviewer overload regions

## Boundary

This model remains replay/review diagnostic instrumentation only.
