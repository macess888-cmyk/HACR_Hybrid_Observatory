# Consequence Locality Decay Mapper

Observer-only instrumentation for inspecting degradation of executable consequence locality under hostile runtime conditions.

## Focus

Maps:
- locality fragmentation
- interruption-distance growth
- representational persistence
- escalation reachability degradation
- continuation hardening

## Non-Claims

This tool does NOT:
- authorize interruption
- classify legitimacy
- govern execution
- orchestrate remediation
- certify safety

## Output Goal

Localize where:
consequence visibility survives after executable interruption realism degrades.
