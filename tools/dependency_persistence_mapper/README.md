# Dependency Persistence Mapper

## Purpose

Localize hidden survivability concentration and operational dependency persistence within complex systems.

---

# Maps

The mapper visualizes:

- hidden dependency concentration
- survivability bottlenecks
- operational coupling
- replay persistence
- interruption propagation
- recovery path fragility

---

# Example

A workflow may appear distributed while operational survivability silently concentrates into:

- single vendors
- isolated operators
- undocumented processes
- hidden API dependencies
- institutional memory concentration

---

# Core Reduction

distributed appearance != distributed survivability

---

# Boundary

Observer-only operational inspection.
