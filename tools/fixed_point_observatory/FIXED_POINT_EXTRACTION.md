# Fixed Point Extraction

## Fixed Point

A structure is a fixed point if:

1. It survives persistence extraction
2. It survives invariant extraction
3. It remains visible after reduction

## Candidate Types

- FIXED_POINT
- FIXED_POINT_CLUSTER
- FIXED_POINT_CORE
- PERSISTENCE_ANCHOR
- STRUCTURAL_ANCHOR

## Boundary

Fixed points are not proof.

Fixed points are not causality.

Fixed points are not authority.

They are observer-visible reduction-stable structures only.
