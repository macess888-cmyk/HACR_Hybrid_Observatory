# Reviewer Onboarding Visuals

## Purpose

This tooling provides reviewer onboarding visuals, animation artifacts, walkthrough flows, and public-safe visual guidance for deterministic recovery case-pack inspection.

## Core Reductions

- Reproducible visuals improve inspection, not authority.
- Green is not viable.
- Visible is not traversable.
- Interrupted is not recovered.
- Being seen is not being protected.
- Layer survival is not layer inheritance.
- UNKNOWN -> HOLD.

## Workflow

1. Run deterministic case pack.
2. Generate SVG outputs.
3. Open onboarding visuals.
4. Compare reductions against rendered outputs.
5. Preserve observer-only interpretation boundaries.

## Boundary

Observer-only.

Not governance.
Not certification.
Not authority.
