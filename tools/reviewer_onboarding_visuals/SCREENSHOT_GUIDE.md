# Screenshot Guide

## Purpose

This guide standardizes reviewer screenshots for public-safe walkthroughs.

## Recommended Screenshots

- case JSON
- generated output JSON
- generated SVG
- layer heatmap
- recovery collapse visualization
- onboarding flow

## Include Footer

Every screenshot should visibly preserve:

Observer-only • Not authority • UNKNOWN -> HOLD

## Avoid

- authority framing
- governance implication
- predictive certainty language
- inevitability framing
- operational instruction framing
