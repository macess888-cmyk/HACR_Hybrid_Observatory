# Replay Reconstructability Index

## Purpose

Observer-restricted instrumentation for estimating whether replay/review surfaces remain materially reconstructable under replay locality fragmentation and semantic density accumulation.

The purpose is not to determine governance legitimacy.

The purpose is to preserve replay falsifiability realism.

---

# Core Reduction

Replay availability is not practical reconstructability.

Replay surfaces may remain technically available while becoming materially unreconstructable under:

- replay locality fragmentation
- dependency accumulation
- semantic density growth
- orchestration persistence
- reviewer traversal overload
- reconstruction timing exhaustion

---

# Measurements

This tool may measure:

- replay path count
- dependency depth
- renderer replay references
- validator replay references
- review traversal surface count
- terminology duplication density

The tool does not interpret meaning.

The tool only measures bounded replay/review structure.

---

# Boundary

This tool does not:

- govern
- authorize
- adjudicate
- certify
- determine legitimacy
- operationalize consequence
- infer inevitability

Replay metrics are not authority.
