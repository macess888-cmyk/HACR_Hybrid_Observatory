# Reviewer Traversal Budget Meter

## Purpose

Observer-restricted instrumentation for estimating replay/review traversal burden under semantic density accumulation and replay locality fragmentation.

The purpose is not to score reviewers.

The purpose is to preserve materially reconstructable interruption falsifiability.

Replay visibility alone does not prove practical reconstructability.

Traversal burden may accumulate through:

- replay locality fragmentation
- semantic density accumulation
- validator recursion
- replay dependency expansion
- orchestration persistence
- reconstruction timing exhaustion

while replay remains technically available.
