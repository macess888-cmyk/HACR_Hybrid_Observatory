# Runtime Human Reachability Visualization Layer

Observer-restricted deterministic visualization layer for runtime-human reachability inspection.

Purpose:

Render bounded runtime relationships so reviewers can materially traverse:

- interruption corridors
- synchronization burden
- continuation persistence pressure
- locality degradation
- recovery fragmentation
- visibility vs reachability decoupling

This layer does NOT:

- govern
- authorize
- adjudicate
- certify
- score legitimacy
- infer inevitability
- determine institutional truth
- operationalize consequence

Visualizations are:

- deterministic
- observer-only
- runtime-local
- non-authoritative
- replay-safe
- bounded
- falsifiable where possible

Core locks:

- A map is not authority.
- Visualization is not admissibility.
- Visibility is not reachability.
- Persistence is not closure.
- UNKNOWN -> HOLD.

Break survivability, not ontology.
