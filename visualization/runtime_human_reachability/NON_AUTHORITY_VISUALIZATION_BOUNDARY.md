# Non-Authority Visualization Boundary

Runtime Human Reachability visualizations are inspection artifacts only.

They may:

- render
- localize
- map
- compare
- replay
- preserve bounded uncertainty

They do NOT:

- govern
- authorize
- adjudicate
- certify
- rank legitimacy
- determine institutional truth
- infer hidden authority
- operationalize consequence
- replace bind proof

Required containment:

- A map is not authority.
- A diagram is not admissibility.
- A visual pattern is not legitimacy.
- A rendered basin is not destiny.
- A visible corridor is not executable interruption.
- Visualization does not create bind.

If visualized conditions cannot be materially measured, reconstructed, or falsified:

UNKNOWN -> HOLD

Break survivability, not ontology.
