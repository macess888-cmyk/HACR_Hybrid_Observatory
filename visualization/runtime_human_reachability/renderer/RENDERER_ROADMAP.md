# Hard Containment Boundaries

The renderer must remain:

- observer-only
- deterministic
- bounded
- replay-safe
- anti-authoritative
- anti-ontology

The renderer must not become:

- governance infrastructure
- predictive engine
- optimization engine
- legitimacy framework
- institutional scoring system

Core locks:

- Persistence is not legitimacy.
- Acceleration is not destiny.
- Visualization is not authority.
- UNKNOWN -> HOLD.

Break survivability, not ontology.
