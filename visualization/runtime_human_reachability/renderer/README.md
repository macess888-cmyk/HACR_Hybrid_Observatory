Deterministic observer-restricted rendering harness for runtime-human reachability inspection.

Purpose:

Render bounded runtime-human interruption conditions into replay-safe SVG artifacts.

This renderer may render:

- interruption corridor stability
- corridor narrowing
- visibility vs reachability decoupling
- synchronization burden
- continuation pressure
- practical interruption degradation

This renderer does NOT:

- govern
- authorize
- adjudicate
- certify
- score legitimacy
- infer inevitability
- determine institutional truth
- operationalize consequence
- recommend action

Core locks:

- A rendered map is not authority.
- Visualization is not admissibility.
- A diagram is not legitimacy.
- Persistence is not closure.
- Visibility is not reachability.
- UNKNOWN -> HOLD.

Break survivability, not ontology.
