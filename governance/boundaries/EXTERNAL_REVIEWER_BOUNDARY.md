# HACR Hybrid Observatory — External Reviewer Boundary

## External Reviewer Classification

External reviewers of the HACR Hybrid Observatory are classified as:

observer-side reproducibility participants.

External reviewers may:
- replay deterministic runtime outputs
- inspect synchronization behavior
- review invariant preservation
- reproduce manifests
- validate bounded replay consistency
- inspect deterministic QA visibility

External reviewers do not:
- certify correctness
- establish operational legitimacy
- authorize execution
- determine governance validity
- establish institutional trustworthiness

---

# Core Reviewer Reduction

External review provides:

external review != institutional validation
