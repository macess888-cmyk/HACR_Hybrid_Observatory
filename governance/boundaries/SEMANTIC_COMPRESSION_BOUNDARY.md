# Semantic Compression Boundary

## Purpose

This file stabilizes the boundary between useful compression and ontology expansion.

The observatory uses repeated reductions to preserve operational clarity.

However, repeated compression must not create:

- inevitability inheritance
- authority inheritance
- legitimacy inheritance
- closure inheritance
- ontology expansion

---

# Safe Compression

Safe compression reduces ambiguity without expanding authority.

Examples:

- Visibility is not reachability.
- Persistence is not closure.
- Asymmetry does not imply destiny.
- Instrumentation is not authority.
- Measurement is not admissibility.
- UNKNOWN -> HOLD.

These phrases are containment locks, not doctrine-producing primitives.

---

# Unsafe Compression

Unsafe compression occurs when repeated language begins to imply:

- inevitability
- destiny
- legitimacy
- authority
- governed truth
- closure
- hidden coordination
- institutional finality

If unsafe compression is detected:

UNKNOWN -> HOLD.

---

# Boundary Rule

Compression may clarify inspection.

Compression must not authorize consequence.

Compression may preserve traversal.

Compression must not create ontology.

Break survivability, not ontology.
