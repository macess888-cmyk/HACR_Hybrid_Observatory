# CYCLE 001 — REDUCTION AGAINST BURDEN DISCHARGE

STATUS: ACTIVE

## Test Method

For each candidate case, ask:

1. Did a responsible authority exist?

2. Was that authority localized?

3. Did the authority fail to discharge the burden?

4. Or was burden discharge impossible because responsibility was not localized?

---

## Case Classification

### Class A — Authority Failure

Burden exists.

Responsible authority exists.

Responsible authority is localized.

Responsible authority refuses, neglects, delays, or fails to discharge the burden.

Result:

HOLD

Interpretation:

Burden Discharge Failure

---

### Class B — Localization Failure

Burden exists.

Responsible authority does not appear localized.

No entity is clearly responsible for discharging the burden.

Burden discharge cannot begin.

Result:

HOLD

Interpretation:

Burden Localization Failure

---

## Reduction Test

If Class A and Class B collapse into the same explanatory category:

Burden Localization weakens.

If Class A and Class B require different remediation paths:

Burden Localization strengthens.

---

## Remediation Test

Class A remediation:

Identify why the responsible authority failed.

Class B remediation:

Identify who, if anyone, owns the burden.

Observation:

If remediation differs, failure class may differ.
