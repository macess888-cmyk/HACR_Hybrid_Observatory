# BURDEN LOCALIZATION CASES

STATUS: ACTIVE

Purpose:

Collect candidate observations before reduction.

This file does not promote Burden Localization.

This file does not establish a primitive.

This file does not establish an invariant.

This file only records candidate cases where transition failure may involve authority localization rather than ordinary authority failure.

---

## Review Question

Did transition fail because:

Authority existed and failed to act?

or

Authority was never localized to an entity capable of acting?

---

# CASE 001 — MULTI-AGENCY RESPONSIBILITY FAILURE

Description:

A transition requires action, approval, repair, escalation, or responsibility across multiple agencies or departments.

Observed Transition:

A required change does not occur.

Observed Failure:

Each participating body may recognize the problem, but no single body is clearly localized as responsible for discharging the burden.

UNKNOWN
