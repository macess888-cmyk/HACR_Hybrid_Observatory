# Non-Authority Boundary

The Runtime Human Reachability Harness is strictly observer-restricted.

The harness may:

- inspect
- instrument
- replay
- localize
- pressure-test
- classify
- preserve bounded uncertainty

The harness does NOT:

- govern
- authorize
- adjudicate
- certify
- operationalize consequence
- replace institutional authority
- replace bind proof
- determine legitimacy
- determine governance truth
- infer inevitability
- inherit authority through visibility
- inherit legitimacy through persistence

Core containment boundaries:

- Instrumentation is not authority.
- Measurement is not admissibility.
- Visibility is not legitimacy.
- Persistence is not closure.
- Evidence does not create bind.
- Replayability does not create authority.
- Explanation does not create consequence legitimacy.
- Human concern does not create admissibility.
- Survivability does not create governance legitimacy.

The harness inspects runtime interruption conditions only.

If runtime conditions cannot be materially measured, reconstructed, or falsified:

UNKNOWN -> HOLD

The harness preserves:

- runtime locality
- interruption-centered falsifiability
- bounded operational semantics
- deterministic inspection
- semantic containment
- anti-ontology posture
- anti-authoritative posture
- anti-inevitability posture

Break survivability, not ontology.
