# Visibility vs Reachability Decoupling

Visibility vs Reachability Decoupling inspects whether operational visibility survives after practical interruption reachability collapses.

The observatory does not determine:

- governance legitimacy
- institutional validity
- political truth
- inevitability

The object is interruption-local observability only.

Primary question:

Can consequence remain operationally visible while executable interruption capability becomes materially unreachable?

Measured runtime surfaces may include:

- interruption visibility persistence
- interruption reachability degradation
- corridor narrowing
- synchronization exhaustion
- interruption locality fragmentation

If visibility conditions cannot be materially reconstructed:

UNKNOWN -> HOLD

If visibility survives after interruption reachability collapses:

FAIL

If interruption reachability remains materially executable:

PASS

Core locks:

- Visibility is not reachability.
- Observation is not interruption.
- Persistence is not closure.
- UNKNOWN -> HOLD.
