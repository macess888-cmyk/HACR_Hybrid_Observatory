# Orbital Continuity Is Not Trajectory Validity

## Core Reduction

An object can remain in orbit after recoverable trajectory validity has already degraded.

Continued motion does not prove preserved recoverability.

## Key Distinctions

- orbital continuity != orbital validity
- telemetry != maneuverability
- prediction != present-state coupling
- stable path appearance != preserved correction corridor
- continued signal != recoverable intervention window

## Observer Scope

This note defines an observer-local orbital continuity inspection surface.

It does not claim:

- orbital control
- mission authority
- autonomous maneuver authorization
- flight safety certification
- command execution legitimacy

## Diagnostic Question

Is the object still coupled to a recoverable trajectory corridor, or is it merely continuing along a degrading one?

UNKNOWN -> HOLD.

Break survivability, not ontology.
