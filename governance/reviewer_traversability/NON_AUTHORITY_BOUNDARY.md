# Reviewer Traversability Non-Authority Boundary

The Reviewer Traversability Layer is strictly observer-restricted.

It may inspect:

- reviewer path burden
- documentation traversal pressure
- semantic density accumulation
- layer discoverability
- reconstruction burden
- complexity/traversability coupling

It does NOT:

- govern
- authorize
- adjudicate
- certify
- rank reviewers
- evaluate competence
- determine legitimacy
- replace institutional review
- optimize human behavior
- operationalize consequence

Core containment:

- Traversability is not authority.
- Reviewer reachability is not legitimacy.
- Documentation clarity is not admissibility.
- Inspection support is not governance.
- Measurement is not bind.

If traversal conditions cannot be materially measured, reconstructed, or falsified:

UNKNOWN -> HOLD

Break survivability, not ontology.
