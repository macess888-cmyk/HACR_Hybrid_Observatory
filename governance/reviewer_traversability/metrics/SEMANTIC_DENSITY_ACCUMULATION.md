# Semantic Density Accumulation

Semantic Density Accumulation inspects whether repeated observability language accumulates enough compression pressure to degrade reviewer traversability.

This is not ontology.

This is semantic traversal pressure inspection.

Primary question:

Does accumulated semantic density materially reduce a reviewer’s ability to reconstruct the observability boundary?

Measured surfaces may include:

- repeated compression phrases
- boundary term density
- coupling term accumulation
- semantic overlap
- containment phrase saturation
- reviewer reconstruction burden

If semantic density cannot be materially reconstructed:

UNKNOWN -> HOLD

If semantic density degrades practical review traversal:

FAIL

If semantic compression remains bounded and traversable:

PASS

Core locks:

- Compression is not authority.
- Repetition is not legitimacy.
- Semantic density is not destiny.
- UNKNOWN -> HOLD.
