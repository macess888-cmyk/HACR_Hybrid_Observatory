# Complexity vs Traversability

Complexity vs Traversability inspects whether observability complexity begins degrading the reviewer’s ability to reconstruct the observatory boundary.

The observatory does not determine:

- reviewer competence
- institutional validity
- governance legitimacy
- authority

The object is runtime complexity pressure only.

Primary question:

Does added observability complexity materially reduce practical reviewer traversability?

Measured surfaces may include:

- layer interaction count
- coupling density
- renderer complexity
- semantic overlap
- reconstruction delay
- documentation depth
- path ambiguity

If complexity/traversability coupling cannot be materially reconstructed:

UNKNOWN -> HOLD

If complexity degrades practical traversal beyond reach:

FAIL

If traversability remains materially preserved:

PASS

Core locks:

- Complexity is not authority.
- Reviewer confusion is not consent.
- Traversability is not legitimacy.
- UNKNOWN -> HOLD.
