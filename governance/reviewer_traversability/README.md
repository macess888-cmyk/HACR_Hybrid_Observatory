# Reviewer Traversability Layer

Observer-restricted layer for inspecting whether the observatory itself remains materially traversable under increasing runtime observability complexity.

Purpose:

Inspect whether reviewers can still materially understand, navigate, reconstruct, and pressure-test the observatory without excessive semantic density, topology overload, or coupling burden.

This layer does NOT:

- govern
- authorize
- adjudicate
- certify
- determine legitimacy
- optimize reviewer behavior
- create authority
- replace institutional review

Core reduction:

The observatory must remain materially traversable or observability itself begins degrading interruption viability inspection.

Core locks:

- Reviewer visibility is not reviewer reachability.
- Documentation density is not clarity.
- Complexity is not authority.
- Traversability is not legitimacy.
- UNKNOWN -> HOLD.

Break survivability, not ontology.
