# Recursive Localization Protocol
Observer-Restricted Contradiction Narrowing Workflow

## Purpose

This protocol describes recursive narrowing procedures used to isolate hidden local inconsistency beneath apparently coherent global state.

The workflow is observer-restricted.

It does not:
- authorize execution
- certify correctness
- establish truth
- replace independent verification

Its purpose is bounded contradiction localization only.

---

# Core Principle

Global coherence may conceal locally survivable contradiction.

Recursive narrowing reduces ambiguity without requiring authority escalation.
