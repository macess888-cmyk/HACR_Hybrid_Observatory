# Terminology Compression

Purpose:
Reduce semantic inflation and overlapping conceptual language inside the observatory.

Core rule:

New terminology must reduce ambiguity more than it increases interpretive scope.

If a term requires excessive narrative explanation relative to executable evidence,
the term should be compressed, simplified, or removed.

---

# Preferred Direction

Prefer:

- concrete inspection language
- deterministic evidence terms
- bounded operational descriptions
- reviewer-legible naming
- minimal semantic overlap

Avoid:

- recursive topology metaphors
- symbolic geometry escalation
- unnecessary abstraction layering
- authority-adjacent terminology
- ontology-heavy phrasing

---

---

# Reviewer Priority

Terminology should optimize for:

1. reproducibility
2. inspectability
3. bounded interpretation
4. executable clarity

not semantic density.

---

# Compression Constraint

If multiple terms describe substantially similar observable behavior:

→ consolidate terminology.

If terminology exceeds executable necessity:

→ compress scope.

---

# Final Principle

Operational clarity should increase faster than terminology count.
