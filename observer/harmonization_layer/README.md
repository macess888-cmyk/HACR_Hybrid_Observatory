# Field Harmonization Lens

Observer-side only.

This layer holds signals, routes differences, and classifies interface compatibility.

It does not:
- validate
- authorize
- optimize
- govern
- resolve
- execute
- certify
- become an operational dependency

Default state: HOLD unless authority, provenance, recovery, and containment are explicitly bounded.

## Outputs

- ADMISSIBLE
- HOLD
- INCOMPATIBLE

These are diagnostic labels only.
They do not authorize propagation or execution.
