# Interface Compatibility

## Docks cleanly

- observer-only artifacts
- deterministic receipts
- reproducible ledgers
- bounded topology maps
- non-authoritative diagnostics

## Requires translation

- social signals into artifact records
- geometric language into executable schemas
- cross-domain claims into typed evidence classes
- formulation differences into translation plates

## Must remain isolated

- authority generation
- optimization logic
- governance inheritance
- narrative inevitability
- observed-therefore-proven claims
