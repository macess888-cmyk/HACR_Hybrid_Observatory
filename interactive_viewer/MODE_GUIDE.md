# HACR Hybrid Observatory — Viewer Mode Guide

## Purpose

The Interactive Viewer now supports multiple bounded observability modes.

Each mode provides visibility only.

No mode predicts, governs, authorizes, certifies, scores, optimizes, or replaces operators.

---

# Modes

## Scenario Mode

Use for:

- loading a specific continuity topology
- viewing nodes, dependencies, pressure panels, corridors, and shadow dependencies
- downloading scenario JSON and receipts

Primary controls:

- Scenario
- Load Scenario
- Open SVG
- Download JSON
- Download Receipt

---

## Atlas Mode

Use for:

- domain navigation
- scenario grouping
- continuity family orientation

Primary controls:

- Healthcare
- Cyber
- AI Oversight
- Energy
- Emergency
- Supply Chain
- Comparison

Atlas mode groups observability surfaces.

It does not assign authority or priority.

---

## Relationship Mode

Use for:

- shared pressure surfaces
- dependency concentration visibility
- fallback corridor overlap
- shadow dependency relationship inspection

Primary controls:

- Human Oversight
- Dependency
- Fallback Corridors
- Shadow Dependencies
- Relationship Graph
- Corridor Geometry

Relationship mode exposes scenario overlap.

It does not score or rank scenarios.

---

## Replay Mode

Use for:

- bounded deterministic continuity evolution traversal
- replay frame stepping
- replay playback

Primary controls:

- First
- Previous
- Load Replay
- Next
- Last
- Play
- Pause

Replay mode does not predict future states.

---

## Delta Mode

Use for:

- frame-to-frame change visibility
- pressure deltas
- recoverability contraction visibility
- node-state transition visibility

Primary controls:

- First
- Previous
- Load Delta
- Next
- Last

Delta mode does not score systems.

---

## Temporal Drift Mode

Use for:

- corridor movement over bounded replay frames
- fallback narrowing / widening visibility
- oversight visibility drift
- dependency pressure movement

Primary controls:

- First
- Previous
- Load Drift
- Next
- Last

Temporal Drift mode does not simulate operational truth.

---

## Field Dynamics Mode

Use for:

- continuity field movement
- pressure propagation visibility
- basin deformation visibility
- corridor elasticity visibility

Primary controls:

- First
- Previous
- Load Field
- Next
- Last

Field Dynamics mode is bounded visualization only.

# NON-CLAIMS

The viewer does not:

- predict future operational states
- govern systems
- authorize execution
- certify recoverability
- replace operators
- provide operational guarantees
- score correctness
- optimize response

The viewer provides:

bounded deterministic observability only.
