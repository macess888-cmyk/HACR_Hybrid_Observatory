# HACR Hybrid Observatory — Reduction Branch Architecture

## Purpose

The reduction branch extracts what remains after observer-visible structure is progressively reduced.

It does not predict.
It does not route.
It does not certify causality.
It does not govern execution.

UNKNOWN → HOLD.

## Layer Meanings

Skeleton:
Structural persistence surviving historical visibility reduction.

Invariant:
Structure visible across every bounded observation epoch.

Fixed Point:
Invariant visibility surviving reduction.

Anchor:
Fixed-point stability surviving additional reduction.

Anchor Basin:
Concentration of reduction-stable anchors.

Anchor Attractor:
Residue of anchor-basin reduction.

Reduction Horizon:
Remaining structural visibility before exhaustion.

Visibility Extinction Boundary:
Boundary where surviving visibility approaches exhaustion.

Reduction Residue:
Irreducible observer-visible structure remaining after reduction.
