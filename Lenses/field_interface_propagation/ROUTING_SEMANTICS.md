# ROUTING SEMANTICS

## Allowed

- read-only visibility
- local containment observation
- compatibility classification
- propagation inspection
- HOLD-state preservation

## Disallowed

- execution routing
- autonomous propagation
- optimization authority
- centralized orchestration
- hierarchy formation
- inevitability framing

## Signal Discipline

The system HOLDS signals.

The system does not validate signals.

The system routes differences.

The system does not resolve differences.

Propagation remains gated by:

- explicit consent
- compatibility
- containment visibility
