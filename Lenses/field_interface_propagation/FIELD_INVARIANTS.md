# FIELD INVARIANTS

## Core Invariants

- single reference geometry
- proportional interface preservation
- local failure containment
- recovery precedes optimization
- signals do not imply authority
- propagation gated by consent and compatibility

## Physical

- enclosure defines limits, not ownership
- platforms dock without deformation
- structural interfaces remain invariant

## Energetic

- shared routing layer only
- platform-local actuation permitted
- field-level dissipation enforced

## Informational

- single source of geometric truth
- versioned artifacts only
- read-only visibility by default

## Social / Partner

- entry by consent
- observation before contribution
- escalation requires explicit authority
