# Governance Theater Survivability Harness

Observer-restricted runtime inspection harness for detecting when governance visibility survives while practical interruption capability collapses.

Purpose:

Inspect whether visible governance mechanisms remain materially connected to executable interruption capability.

This harness does NOT:

- govern
- authorize
- adjudicate
- certify
- determine legitimacy
- accuse institutions
- infer political failure
- infer hidden authority
- infer inevitability
- operationalize consequence

Core reduction:

Governance theater is not a legitimacy claim.
It is a runtime-local interruption reachability failure mode.

Primary detector:

Can visible governance mechanisms still materially interrupt consequence?

YES -> PASS
UNKNOWN -> HOLD
NO -> FAIL

Core locks:

- Governance visibility is not interruption capability.
- Oversight visibility is not executable interruption.
- Review presence is not reachability.
- Escalation existence is not interruption viability.
- Persistence is not legitimacy.
- Asymmetry does not imply destiny.
- UNKNOWN -> HOLD.

Break survivability, not ontology.
