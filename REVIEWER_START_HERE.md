# Core Interpretation

This repository inspects whether practical interruption remains materially reachable under runtime continuation pressure.

It does not decide whether a system is legitimate.

It does not replace institutional authority.

It does not create admissibility.

---

# Verdict Semantics

PASS:
runtime conditions remain materially inspectable and interruption remains reachable.

HOLD:
runtime conditions cannot be materially measured, reconstructed, or falsified.

FAIL:
interruption reachability materially collapses under continuation pressure.
