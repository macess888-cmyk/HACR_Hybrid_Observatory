## Repository Purpose

The HACR Hybrid Observatory is an observer-restricted runtime continuity inspection and survivability observability framework.

The repository inspects whether practical interruption viability remains materially reachable under runtime continuation pressure.

The repository does not determine:

- governance legitimacy
- institutional authority
- operational truth
- admissibility
- inevitability
- consequence permission
