# Semantic Compression Rules

## Purpose

Prevent uncontrolled ontology expansion, semantic drift, and authority inflation.

Maintain runtime-local, reviewer-facing, falsifiable inspection boundaries.

## Compression Rules

All repository concepts should remain:

- runtime-local
- interruption-relevant
- reproducible
- falsifiable
- reviewer-inspectable
- bounded
- removable

If unclear:

-> HOLD

## Runtime Compression Rule

If a concept cannot compress into:

- runtime locality
- interruption visibility
- reproducibility
- falsifiability
- reviewer inspectability
- bounded operational behavior

-> HOLD

## Drift Indicators

Potential semantic drift indicators include:

- recursive semantic refinement without new operational evidence
- observer centrality growth
- continuity dependence
- execution-adjacent influence
- conceptual expansion outrunning inspectability
- usefulness becoming legitimacy
- coherence becoming substitute validity
- reviewer familiarity reducing falsification pressure
- semantic survivability replacing runtime locality

## Stabilization Signals

Healthy stabilization signals include:

- boundedness
- replayability
- interruption locality
- explicit invalidity
- removability
- reviewer challengeability
- deterministic outputs
- operational compression
- periodic disengagement

## Anti-Authority Rules

The repository may not become:

- governance authority
- execution infrastructure
- semantic centrality layer
- operational dependency substrate
- environmental continuity carrier
- generalized truth framework

## Key Reductions

- coherence is not admissibility
- usefulness is not legitimacy
- continuity is not coupling
- recursive coherence is not runtime validity
- observer persistence is not governance authority
- borrowed continuity is not admissibility

## Reviewer Rule

The repository becomes stronger by becoming:

- narrower
- more inspectable
- more removable
- more reproducible
- more falsifiable
- easier to independently challenge

Not by increasing semantic scope.

## Final Compression

A healthy branch compresses faster than ontology expands.
