# HACR Hybrid Observatory — Public Viewer

This site hosts the public bounded observability viewer for:

- continuity topology inspection
- deterministic replay traversal
- frame delta overlays
- operational continuity cartography

The viewer remains:

- observer-only
- deterministic
- bounded
- non-authoritative
- externally reviewable

The observatory does NOT:

- predict
- govern
- authorize execution
- certify recoverability
- replace operators
- provide operational guarantees

Current release includes:

- multi-domain topology rendering
- replay traversal
- frame delta visibility
- replay receipts
- delta receipts
- interactive continuity cartography
