- replay realism
- traversal realism
- interruption reconstructability
- continuation destabilizability
- recoverability realism

- differential survivability gradients

- traversable
- interrupt-compatible
- destabilizable
- reconstructable
- recoverable
- reviewer-reachable

under bounded runtime conditions.

- observer-only
