# HACR Hybrid Observatory — Interactive Viewer

## Purpose

The Interactive Viewer provides:

bounded deterministic operational continuity visibility
through observer-only topology inspection.

The viewer allows:

- continuity topology inspection
- replay traversal
- frame delta visibility
- continuity pressure inspection
- recoverability corridor visibility
- deterministic artifact review

without:

- prediction
- operational authority
- governance automation
- scoring
- execution authorization
- recovery guarantees
