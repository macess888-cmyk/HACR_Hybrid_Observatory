# What Is Renderer Dependence?

Renderer dependence occurs when understanding depends too heavily on visuals.

Examples include:

- dashboards
- SVGs
- screenshots
- graphs
- visual layouts

Visuals can be extremely useful.

However:

visual smoothness does not automatically prove operational clarity.

A mature observatory should remain understandable even when:

- visuals fail
- screenshots disappear
- dashboards degrade
- or rendering becomes incomplete.

Operational clarity should survive renderer failure.
