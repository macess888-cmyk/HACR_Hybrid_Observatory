# Website Demo Surface

This page defines the current public-facing observatory demo surface.

## Current Public Message

The HACR Hybrid Observatory builds bounded observability and recoverability inspection tools for complex operational systems.

The goal is not prediction or control.

The goal is making hidden continuity pressure easier to inspect.
