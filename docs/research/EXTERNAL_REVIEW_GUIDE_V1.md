# What Is This Branch?

This branch explores a candidate research object:

Protected Investigability

The branch does not assume the object exists.

The branch does not assume the object is explanatory.

The branch attempts to pressure test the candidate through falsification, case studies, comparative review, reduction, and synthesis.

---

# What Is Being Asked?

Primary Question:

What conditions allow meaningful investigation to continue?

Secondary Questions:

Can those conditions be observed?

Can they be compared across historical cases?

Can competing explanations better explain the observed evidence?

---

# What Is NOT Being Claimed?

* An invariant has been established.
* A universal theory has been established.
* A governance model has been established.
* A causal mechanism has been established.

# How To Review This Branch

A reviewer is encouraged to ask:

What assumptions are hidden?
