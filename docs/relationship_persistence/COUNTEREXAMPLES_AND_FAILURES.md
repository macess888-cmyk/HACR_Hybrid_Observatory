# Failure Criteria

The branch weakens if:

* questions do not change interpretation
* constitutive relationships cannot be distinguished from ordinary dependencies
* continuity surfaces never affect conclusions
* divergence inspection produces no new observations
* identical geometry appears regardless of case

---

# Success Criteria

The branch strengthens if:

* non-obvious observations appear
* counterexamples reveal boundaries
* constitutive relationships differ from ordinary dependencies
* continuity surfaces change interpretation
* divergence timing reveals previously hidden structure
