# Observer-Only Review Guide

## Review Question

Does the repository inspect continuity/recoverability divergence without producing authority?

## Checkpoints

A reviewer should verify that tools and documents remain:

- observer-local
- deterministic
- reproducible
- diagnostic-only
- non-authoritative
- non-certifying
- non-executional

## Red Flags

Flag any wording that implies:

- certification
- authorization
- prediction
- management guidance
- intervention legitimacy
- governance authority
- operational command
- human behavior control

## Receipt Review

Receipts should include:

- tool name
- version
- observer mode
- bounded input snapshot
- classification
- reason
- authority: none
- non-claims
- receipt hash where applicable

## Accepted Classifications

- PASS
- HOLD
- FAIL
- SHADOW
- REVERSE
- STOP

## Required Containment

UNKNOWN -> HOLD.

No present-state proof means no stronger observer-local conclusion.
