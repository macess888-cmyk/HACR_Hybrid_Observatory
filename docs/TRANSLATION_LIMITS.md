# Translation Limits

Translation is an observer-side operation.

## Core Rule

Translation preserves inspectability.

Translation does not imply equivalence.

Equivalence does not imply authority.

Authority does not propagate through observation.

## Allowed

This layer may:

- map formulation differences
- identify semantic mismatch
- preserve provenance
- classify compatibility
- expose unresolved assumptions
- hold ambiguous signals

## Not Allowed

This layer may not:

- validate claims
- collapse disagreement
- certify equivalence
- authorize execution
- create governance authority
- convert observation into permission
