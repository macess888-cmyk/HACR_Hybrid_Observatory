# What Is Consequence Locality?

Consequence locality means interruption can still materially affect the relevant consequence before the system hardens around continuation.

A system may still show:

- dashboards
- replay
- alerts
- escalation paths
- audit logs
- explanations
- and governance visibility

while the practical ability to affect consequence has already weakened.

The core question is:

Can interruption still arrive in time to matter?

If not, representation may survive while runtime governability collapses.
