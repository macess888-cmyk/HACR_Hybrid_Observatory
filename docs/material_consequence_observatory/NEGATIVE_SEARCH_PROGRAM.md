# Purpose

The purpose of this program is to search for evidence that weakens, falsifies, or invalidates the strongest surviving observatory reductions.

This program assumes that surviving reductions should be subjected to stronger pressure than non-surviving reductions.

The objective is not confirmation.

The objective is failure discovery.
