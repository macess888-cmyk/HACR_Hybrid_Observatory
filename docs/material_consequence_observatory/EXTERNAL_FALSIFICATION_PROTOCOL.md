# Material Consequence Observatory — External Falsification Protocol

Status: Experimental v0.5 Candidate

Mode: Observer-only inspection

Control posture:

UNKNOWN → HOLD

---

# Purpose

This protocol defines how external reviewers should attempt to falsify, invalidate, reduce, or pressure the Material Consequence Observatory.

The objective is not agreement.

The objective is failure discovery.

A successful review is one that identifies:

* architectural weakness
* primitive failure
* transition failure
* localization failure
* reduction failure
* explanatory limits

before stabilization claims are made.

---

# Reviewer Objective

Do not attempt to confirm the observatory.

Attempt to break it.

Question:

```text
What consequence paths cannot be localized
using the current framework?
```
