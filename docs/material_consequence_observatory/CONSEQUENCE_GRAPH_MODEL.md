# Consequence Graph Model

## Status

Experimental v0.3  
Material Consequence Observatory geometry layer.

## Purpose

The Consequence Graph Model defines how the Material Consequence Observatory represents material consequence pathways without generating material capability.

It provides a relationship geometry for observer-only inspection.

It does not provide synthesis guidance.

It does not provide optimization guidance.

It does not provide deployment guidance.

It does not provide weaponization guidance.

UNKNOWN → HOLD.

---

## Core Reduction

Capability asks:

> What can be done?

Consequence observability asks:

> What begins changing once it is done?

The Consequence Graph Model exists only on the consequence-observability side of this boundary.
