# Hospital Continuity Scenario

Deterministic observer-only operational continuity demonstrator.

## Focus Areas

- staffing degradation
- recoverability narrowing
- hidden dependency concentration
- operational continuity pressure
- localization degradation
- interruption realism

## Scenario Artifacts

- JSON scenario input
- deterministic SVG output
- reproducible receipts
- observer-only visualization

## Non-Claims

This demonstrator does not:
- predict outcomes
- govern operations
- provide medical guidance
- certify resilience
- replace operators
