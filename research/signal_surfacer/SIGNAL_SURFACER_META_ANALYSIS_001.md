# Failure Mode 001

## False Localization

Definition:

The framework identifies a hidden signal where only missing information exists.

Example:

A market price moves upward.

Options positioning is unavailable.

The framework incorrectly concludes that dealer hedging caused the movement.

Correct disposition:

UNKNOWN → HOLD

# Failure Mode 002

## Interpretive Self-Capture

Definition:

The framework begins producing interpretations instead of localizing signal conditions.

Example:

Signal Surfacer observes interpretation drift, then produces a conclusion about motive or truth without evidence.

Correct disposition:

Return to localization.

Intent remains hypothesis.

Truth remains outside scope.

# Failure Mode 003

## Representation Fixation

Definition:

The framework over-applies the visible-layer versus load-bearing-layer pattern even when the case may involve another structure.

Example:

Every case is forced into:

Representation ≠ Load-Bearing Reality

even when the actual failure may be timing, noise, randomness, overload, accident, or incomplete observation.

Correct disposition:

Allow alternative geometries.

Do not force recurrence.
