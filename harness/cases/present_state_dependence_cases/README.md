# Present-State Dependence Cases

Purpose:

Pressure-test asymmetry between:

- continuity preservation
- replay stability
- reviewer agreement
- operational trust

and:

- present-state dependence
- topology visibility
- live dependency visibility
- runtime grounding

Core reduction:

continuity preserved
≠
present-state dependence preserved

The purpose is not to prove invalidity.

The purpose is to inspect whether:
trusted continuity progressively requires less present-state grounding underneath preserved coherence.

The cases remain:

- observer-restricted
- bounded
- replay-oriented
- non-authoritative
- uncertainty-preserving
